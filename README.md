# Réseau

Ta connexion en un coup d'œil, dans NeoDex.

- **Tester ma connexion** : le ping vers ta box, vers Internet et vers League of Legends (EUW), la gigue,
  les pertes, la vitesse du DNS, et une phrase qui dit d'où vient le problème s'il y en a un.
- **Wi-Fi enregistrés** : les réseaux que ton PC connaît, avec leur mot de passe (lu seulement quand tu
  cliques sur « Afficher ») et un bouton pour le copier.

Les serveurs de jeu de Riot ne répondent pas au ping : Réseau mesure l'entrée du réseau de Riot, juste avant
eux. Le vrai ping en partie est quelques millisecondes plus haut.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Réseau → Installer**.

## Développer un plugin

Le format et le guide sont dans le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
